# 错因分类、信心标注与疑似蒙对（error_taxonomy）

> 升级自 test_tutor@a25df33 的 `references/error_taxonomy.md`（CPKG 四分类、信心三档、两条伪装漏洞规则）。
> 本文是错因与信心的方法论真源：`mastery_calc.py` 与 `weekly_report.py` 消费本文定义的枚举值；
> 推理链的**判定方法**在 `grading_guide.md`，本文只定义它的**统计含义**。

## 1. 这份文档管什么

- 作答后如何在 `answer_log.csv` 里标注「信心」「错因(CPKG)」「推理链」三列；
- 什么情况触发伪装漏洞检测、检测到之后做什么；
- 谁来标注（你自标为主，AI 提示为辅）。

列契约（表头逐字）：`date,模块,题型,对错,信心,错因(CPKG),是否留出集`；v1.5 追加 `溯源,推理链,anki状态`（附加列，缺列不影响旧日志）。
`信心 ∈ {稳,不确定,蒙}`、`错因(CPKG) ∈ {C,P,K,G,无}`、`推理链 ∈ {成立,不成立,未写}`；空值 = WARN，不阻断。

## 2. 信心三档（作答前标注）

| 档位 | 含义 | 计算用值 |
|---|---|---|
| 稳 | 我确信这个答案对 | 1.0 |
| 不确定 | 有倾向但不敢保证 | 0.5 |
| 蒙 | 基本靠猜 | 0.2 |

- **先标后答**：信心在出题之后、作答之前标注。事后补标有自我服务偏差——答错后倾向把原本的「稳」改口成「蒙」，直接污染第 5 节的高置信度错误检测。
- 信心可空但不建议空：空只报 WARN，但会让「稳而错」检测失明。实在没把握就标「蒙」，别留空。
- 信心与错因相互独立：信心回答「作答时有多确定」，错因回答「为什么错」——「稳」而错可能是 C/P/K 任一种。

## 3. 错因四分类（CPKG）

| 代码 | 类型 | 定义 | 处置策略 |
|---|---|---|---|
| C | 概念性错误 | 对核心概念理解错误 | 返回讲解材料（优先走讲授流水线），重新出同类题 |
| P | 程序性错误 | 步骤/方法正确但执行出错 | 提供分步模板，练习同类题 3 道 |
| K | 粗心 | 明知正确答案但因疏忽选错 | 标记为「疑似伪装的概念漏洞」，下次同类题重点关注 |
| G | 覆盖缺口 | 完全未学该知识点 | 加入学习计划，优先安排 |

### 3.1 自标辅助：K 与 C 的边界

「粗心」最容易被当垃圾桶用，一滥用，第 4 节的检测就失效。自标 K 之前先自问两句：

- 盖住答案重做一遍，还能做对吗？能 → 偏 K；不能 → 偏 C。
- 能向别人讲清这道题考的概念吗？能 → 偏 K；不能 → 偏 C。

两问都是「盖住答案重测自己」，比回忆「我当时是不是粗心」可靠——事后回忆会自我美化。

### 3.2 与推理链的关系（v1.5）

CPKG 回答「这次错在哪」，推理链回答「这次对得有没有依据」。两者正交：

- 答错的行：链态只做诊断（是结构没搭起来，还是搭对了但执行错），**不改变 CPKG 的选择**。
- 答对的行：链态是唯一的诊断信息（`不成立` → 疑似蒙对）。

## 4. 规则①：反复粗心 → 疑似概念漏洞

```
if 同一知识点出现 ≥3 次 K 类错误:
    自动将该知识点标记为 "疑似概念漏洞"
    下次出题时强制出题（不受复习调度限制）
    并要求用户写出解题步骤（而非仅选答案）
```

- 「同一知识点」按 `answer_log.csv` 的「模块」列计；「≥3 次」指该模块 K 类错误的累计行数。
- `weekly_report.py` 负责聚合并输出触发清单；会话内 AI 据此提示，并在下次出题时执行「强制出题 + 要求写步骤」。
- 脚本**只提示、不改日志**；标记的移除由你拍板，不建议自动清除。

## 5. 规则②：高置信度错误（「稳」但答错）

- 「稳」意味着主观掌握感很强；答错说明存在虚假掌握感。这类错误对长期学习威胁最大——你不会主动复习自己觉得已经会了的东西。
- **处置**：立即标记最高优先级；下一次复习必须出题；要求解释为什么选该答案。
- 与规则①相互独立、并行生效；同一行日志可以同时喂给两条规则。

### 5.1 触发矩阵

| 本次/累计日志特征 | 触发 | 动作 |
|---|---|---|
| 同模块 K 错累计 ≥3 次 | 规则① | 疑似概念漏洞 + 强制出题 + 要求写解题步骤 |
| 信心=稳 且 对错=错 | 规则② | 最高优先级 + 下次必出 + 要求解释为什么选该答案 |
| 两者同时成立 | ①＋② | 双标记：写步骤 + 写选择理由 |
| 其余 | 无 | 常规 CPKG 处置（第 3 节表） |

## 6. 疑似蒙对（v1.5 新增）：答案对但推理链不成立

定义：`对错=对` 且 `推理链=不成立`。

- **它不是 CPKG 的第五类**，而是与 CPKG 并列的第二个维度：CPKG 描述「错在哪」，链态描述「对得有没有依据」。所以它**不占用错因列的枚举值**，答对行的错因本来留空或写「无」。
- **统计含义**：该行不计入掌握度分子（`mastery_calc.py` 在正确率、高置信度惩罚、趋势三处按错计）。原因很直接：运气不是掌握，把它算进去会让后续复习优先级排错——你会以为自己已经会了，然后不再复习。
- **处置**：强制进变式题池；变式题必须写出完整推理链，不能只给答案。
- **与规则②的交集**：`稳 + 对 + 不成立` 是最强信号——主观确信、答案正确、依据不成立，说明是「记住了结论但不知道为什么」。这类行的惩罚与「稳而错」同权（都进高置信度惩罚），并在周报里单列。
- **不惩罚 `未写`**：外部录入题（习题课、作业）本来就常无过程；技能出的题不该留空，但留空只提示、不扣分。这样外部题不会因为格式问题被系统性低估。
- **谁来判**：练习层由 AI 判（须引作答原句，见 `grading_guide.md` §2）；测量层由你对照 `held_out.md` 的关键步骤清单自判，不让模型参与。

### 6.1 三态一览

| 对错 | 推理链 | 记账 | 掌握度 |
|---|---|---|---|
| 对 | 成立 | 正常答对 | 计入分子 |
| 对 | 不成立 | 疑似蒙对 | **按错计** |
| 对 | 未写 | 正常答对 + 周报提示 | 计入分子 |
| 错 | 任意 | 正常答错 | 不计入分子（原逻辑） |

## 7. 归因主体：你自标为主，AI 提示为辅

- 标注权在你：你最清楚自己错题当时的心理状态。
- AI 只在检测到模式时提示，典型话术：「该知识点已累计 3 次 K，可能不是粗心而是概念漏洞，建议按疑似概念漏洞处置」。
- **不设 AI 自动改写你的标注**：你写 K 就按 K 计；AI 的提示只出现在会话与周报里，不回写 `answer_log.csv`。
- 唯一由 AI 代写的字段是「推理链」的初判——它必须附原句依据，你可以当场改判。
