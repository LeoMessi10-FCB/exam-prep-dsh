# 出题规范：溯源、可判链、变量化（item_writing_guide）

> 升级自 test_tutor@a25df33 的 `references/item_writing_guide.md`。v1.5 增加两条硬约束：
> 每题必须有**可核验的来源标签**、每题必须**能引出推理链**。原有的采题四层防御、出题骨架、变量化与反馈闭环保留。

## 1. 采什么、不采什么

AI 的默认行为是从训练数据里「记得」的真题生成题目——这类题可能只是**记忆回放**，不是真实考题，还常把不同年份的题目混合。四层轻量防御（不做大规模自动核验）：

1. **元数据必填**：每道真题记录来源（年份/地区/题号）。
2. **来源可疑即降权**：AI 自己生成或来源不明的题，标「低可信度」，不进入核心练习序列。
3. **抽样核验**：每批题里抽 1–2 道，人工比对真题原文（或用外部模型交叉验证）。
4. **宁缺毋滥**：题目质量不确定时，宁可少出，也不要用 AI 幻觉题填充练习量。

## 2. 出题约束（六条）

1. **优先真题**：材料里有真题就用真题，其次改真题，最后才是完全新编。
2. **改了真题必须保留原题的考查意图**：改数字、改情境可以；把考查「对比辨析」改成考查「记忆复述」不行。
3. **每道 AI 生成题标注 `[AI 生成]`**，与真题混排时不得抹去标记。
4. **难度对齐原题**：不许用偏难怪题刷正确率。
5. **一次只出一个模块的题**：混模块出题会让错因归因失效（错因列按模块记账）。
6. **每题必须能引出推理链**：题干要问「为什么 / 依据是什么 / 哪一步排除了 X」，不能只有「下列说法正确的是」这种无法追问依据的纯记忆复述；纯记忆题只用于 M-C 档或抽查。

## 3. 溯源硬规则（v1.5 新增）

每条题目、每条判分依据都要能指回材料的具体位置，否则 AI 的「补充解释」会被当成材料原文记住。

| 情形 | 写法 | 例 |
|---|---|---|
| 答案在材料里 | `[材料 <文件名> p.N]` | `[材料 2024真题 p.2]` |
| 材料按小节组织、无页码 | `[材料 <文件名> §<小节标题>]` | `[材料 遗传学讲义 §3.2 分离定律]` |
| 材料页码不可靠（扫描件、手机翻拍） | 用 §小节，或先转写打页码锚点（见 `external_transcription.md`） | — |
| 答案不在材料里，是 AI 推的 | 固定句：**「`[AI 补充]`：本条依据不在所给材料中，属推断，请以官方资料核对」** | 一字不改 |

- **页码来源**：外部 AI 转写时已要求逐页打 `<!-- p.N -->` 物理页码锚点（`external_transcription.md`），`[材料 X p.N]` 的 N 就取该锚点，不要重新估算。
- **一处一句**：一行日志只放一个来源标签；同一题多来源时用 `；` 连接，每个都带 `[材料 …]` 前缀。
- **不许编页码**：不确定页码就不写页码，改用小节；小节也不确定就标 `[AI 补充]`。编错页码比不写更糟——它会让一条幻觉获得「有出处」的外观。
- **落账位置**：`answer_log.csv` 的 `溯源` 列（附加列）。`validate_log.py` 只校验括注形态，不校验页码真实性；真实性靠你在会话里当场核对。
- **Obsidian 双链**：若你希望笔记里是可点击的双链，直接在溯源里写 `[[笔记名#标题]]`（AI 在会话里知道源笔记名时就这么写）；`obsidian_sync.py` 会把无法解析的链接报 WARN。

## 4. 出题骨架（可复制）

```
请按以下结构出题，不要输出解题过程：

【模块】<取自 syllabus_table.csv 的模块列，逐字一致>
【题型】客观 / 主观
【来源】[材料 文件名 p.N] 或 [材料 文件名 §小节] 或 [AI 补充]
【题干】<真题原题或改造后的题面；改造处注明「改自 <年份> 真题第 N 题」>
【选项】A/B/C/D（客观题必填；干扰项须反映常见误解，见 §5）
【答案】<客观题给答案；主观题给采分点清单>
【关键步骤清单】1. ... 2. ... 3. ...   ← 供批改判链与测量层自判
【推理链要求】客观题：作答时写一行依据（用到的条件/规则 + 为什么排除其它选项）
              主观题：作答时体现上述关键步骤
```

- **顺序固定**：先给模块与来源，再给题目。缺失【来源】的题不许出——这是第 3 节的硬规则在出题环节的落点。
- 关键步骤清单是后两步的输入：批改的链判定表（`grading_guide.md` §4.1）、测量层的自判依据（`measurement_guide.md` §2）。出题时省掉它，后面两步都没有依据。
- 同一模块连续出题时，把上一题的错误模式写进下一次的【干扰项】，形成针对性。

## 5. 干扰项示例

判断题：同一模块下，正确选项与干扰项应只有一处差异。

- 正确答案：A（因为条件 X 成立，规则 R 适用）
- 干扰项 B：名词混淆（把概念 Y 的描述套到概念 X 上）
- 干扰项 C：把充分条件当必要条件（反向推理）
- 干扰项 D：正确规则用错对象（规则 R 对，但用在不适用的情况）

选择题：干扰项必须对应一类真实误解，不能靠「明显荒谬」凑数——同义改写、程度夸大、因果颠倒，都比「完全无关」更能区分掌握与不掌握。

填空题：空位只挖关键概念或关键数值；同时挖两个互相依赖的空，会变成一道隐藏的连带题。

小题量真题：一个真实材料通常能撑 3 道客观题 + 1 道主观题。

- 第 1 问：直接提取（细节定位）
- 第 2 问：推断（根据 A 推出 B）
- 第 3 问：对比辨析（两个易混概念的区别）

## 6. 变式题：必须真变量化，不能换皮

同一考点、不同情境、同样难度。三种变量化方式（至少用一种）：

- **换情境**：换数字、换案例、换材料，保留考查意图。
- **换问法**：把「正确的是」改成「错误的是」，或改成「若 X 换成 Y，结论如何变化」。
- **换呈现**：从文字题改成图表/表格/数据描述（条件允许时）。

反例：只换人名或只改选项顺序——这是换皮，不是变式，正确率会虚高，变式题也就失去了检验价值。

### 6.1 v1.5：变式题池从三类扩到四类

| 池 | 来源 | 出题侧重 |
|---|---|---|
| A. 错题变式 | `错因(CPKG)` ∈ {C,P,K,G} 的模块 | 按 C/P/K/G 分别处置（`error_taxonomy.md` §3） |
| B. 疑似概念漏洞 | 同模块 K 错 ≥3 | 强制出题 + 要求写解题步骤 |
| C. 最高优先级 | `信心=稳 且 对错=错` | 要求解释「为什么选该答案」 |
| D. **疑似蒙对**（新增） | `对错=对 且 推理链=不成立` | 变式题**必须写出完整推理链**，只给答案判为未完成 |

池 D 的题不许只问答案：题干要问「你的依据是什么」「哪一步排除了 X」，否则它又会变成一次蒙对。

## 7. 反馈闭环

两道变式题的正确率明显低于原题 → 干扰项太像或题干有歧义 → 下一轮把干扰项改得更具体。这是提示词工程的正常迭代，不是技能缺陷。

闭环的落点：

```
出题 → 作答 → 批改（链 + 采分点）→ 落账（对错/信心/错因/推理链/溯源）→ 更新掌握度 → 下一轮出题
```

- 每轮只需闭环一次，不必为单道题反复追问。
- 变式题连续两次都做对且链成立 → 该模块本轮可以不再出题（腾出时间给更弱的模块）。
- 变式题做对但链不成立 → 按疑似蒙对处理，回池 D。

## 8. 与留出集的边界

- 出题材料只来自日常池；`held_out.md` 从不作为出题来源，也不作为变式题的参照（`measurement_guide.md` §1）。
- 若你怀疑某道日常题与留出集重复，宁可换题：重复不会伤害练习，但会让测量失效。

## 9. 与其他文件的衔接

- `SKILL.md`：日常循环第 2 步（出题前先读掌握度）与第 3 步（出题）引用本文 §2–§4。
- `material_tiers.md`：不同材料档能出什么题（M-C 档只能出练习层题目）、`[AI 补充]` 的使用边界。
- `grading_guide.md`：本文的关键步骤清单是批改「链判定表」的输入。
- `error_taxonomy.md`：变式题池 A–D 与错因/信心/链态的对应关系。
- `external_transcription.md`：页码锚点是 `[材料 X p.N]` 的唯一来源。
- `measurement_guide.md`：留出集与日常池的隔离。
