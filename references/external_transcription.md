# 外部视觉 AI 转写模板（external_transcription）

> 场景：本机不做 OCR（蓝本边界）。扫描版真题（如微积分 A(1) 2020/2023 四场）与手写笔记，用外部视觉大模型（豆包 / Kimi / ChatGPT / Gemini 等支持文件上传的对话 AI）转写后回流入库。
> 本文件 = 粘贴给外部 AI 的**提示词** + **回流质检规则**。外部执行、技能落账：转写质量由外部模型负责，是否可用由本文质检负责。

## 1. 提示词（整体复制，随文件一起发给外部 AI）

```
你是专业的试卷数字化录入员。我会给你一份扫描版 PDF（考试试卷或课堂笔记）。请把它逐字转写为 Markdown，规则如下：

【忠实性（最高优先级）】
1. 只转写页面上真实可见的内容：不补题、不纠错、不翻译、不概括、不添加原文没有的步骤或答案。
2. 看不清的字符用「（不清）」占位；数学符号无法确认时写最接近的形式并加「?」。
3. 页眉、页码、水印、装订孔标记一律忽略（页码只用于下面的锚点，不写进正文）。

【页码锚点（v1.5 必需）】
4. 每页开始处输出一行 HTML 注释 <!-- p.N -->，N 为该 PDF 的物理页码（从 1 开始计，不是卷面印刷页码）。
5. 每道大题题头前保留可作锚点的标题行（如「一、选择题（共7题，每题3分，共21分）」），该行原样转写、行首加 ## 。
6. 一页跨多个大题、或一个大题跨多页时，锚点照常按页输出：<!-- p.N --> 只标记页起点，不标记题目归属。

【结构】
7. 大题题头原样保留为一行，行首加 ## 。
8. 题号保持「1.」「2.」编号格式；选择题选项各占一行，保留 A. B. C. D. 前缀。
9. 若卷面印有答案或解析（含「解：」「证明：」字样），原样转写，并在该部分前加一行 <!-- 解析开始 -->。
10. 手写内容与印刷内容分开：手写段落每段前加【手写】标记。

【数学式】
11. 公式用行内 LaTeX（$...$）：如 $\int_0^1 f(x)\,dx$、$\frac{dy}{dx}$、$\lim_{n\to\infty}$；分式、上下标、积分上下限必须结构完整，禁止拍平成单行乱码。

【输出】
12. 第一行输出元数据：卷别:（能识别的年份/场次；识别不了写「未知」）。
13. 之后直接输出 Markdown 正文；不要任何解释、开场白或总结。
```

- **`<!-- p.N -->` 是 v1.5 溯源标签 `[材料 文件名 p.N]` 的唯一来源**：没有锚点，后面写出来的页码只能是猜的。提示词里这条不可省、不可改成「尽量标注」。
- 公式仍要求**行内 LaTeX**；手写与印刷**分开**；看不清一律「（不清）」——三件事一起构成「可判分」的下限：公式结构完整才判得了步骤分，手写标记才分得清原卷与批注，（不清）才留得下「这里不可信」的证据。

## 2. 使用要点

1. **一份 PDF 一次对话**；页数多时分批（每次 5–10 页），提示词尾部加一句「本批为第 X 部分，从上页末行续写」，并保证**跨批的页码锚点连续**（第二批从 `<!-- p.11 -->` 起，不要从 p.1 重新数）。
2. 手写笔记转写质量天然低于印刷体——外流前先抽一页试转，能接受再全量。
3. 把考试材料上传第三方 AI 属你自己的数据流出决策；真题版权件上传前自行斟酌。

## 3. 回流质检（入库前必做，会话内 AI 执行）

转写文本拿回会话后，逐条过下面五项；任何一项不过，退回重转或降级使用：

1. **题号连续性**：题号无跳号、无重号（跳号 = 疑似漏页或漏题；重号 = 疑似跨批重复）。
2. **大题结构对照**：与相邻年份卷的大题结构对照（期中/期末各自的结构惯例），缺整块大题 = 疑似漏页，退回补转；大题题头须含分值（「共N题，每题N分」模式）。
3. **「（不清）」密度**：单卷「（不清）」超过 **20 处** → 转写质量不合格，换模型或提高扫描分辨率重转，不要硬着头皮入库。
4. **页码锚点覆盖率**（v1.5 新增）：**每页都应有 `<!-- p.N -->`**。逐页核对 N 与物理页码是否一致；缺失的页必须补锚点（回到原文定位该页起止），**因为缺锚点的材料只能被迫标 `[AI 补充]`，溯源等级下降**——能标 `[材料 文件名 p.N]` 的结论被降成 AI 生成，等于白转。
5. **抽查 3 处引用**（v1.5 新增）：随机挑 3 处转写内容，按其 `p.N` 回原文核对，确认**页码对得上**、内容也对得上。抽 3 处全对可入库；有一处页码错位，先把该页之后的锚点整体校正再抽。

通过后落库；任一项未过而仍要用，必须在 `INDEX.md` 记一句「转写质量降级 + 原因」，让后续会话知道这份材料的可信度。

## 4. 合格片段示例（对照用，非正文模板）

```
卷别: 2020 期中

<!-- p.3 -->
## 一、选择题（共7题，每题3分，共21分）

1. 下列函数在 $x=0$ 处连续的是（　）
A. $\frac{\sin x}{x}$
B. $\frac{1}{x}$
C. $|x|$
D. $e^{1/x}$

2. 设 $f(x)=\int_0^x \frac{1}{1+t^2}\,dt$，则 $f'(0)=$（　）

<!-- p.4 -->
3. 计算 $\lim_{x\to 0}\frac{\sin 3x}{x}$。
```

- 锚点写在**页起点**，且 N 与 PDF 物理页码一致；每页恰好一行 `<!-- p.N -->`，不要在注释里附加文字（自动化提取锚点按此单一形式匹配）。
- 大题题头单独成行，行首 `## `，便于后续按「大题 → 题号 → p.N」建立溯源。
- 常见退件：锚点被写进正文段落中间、用「第 3 页」代替 `<!-- p.3 -->`、跨批转写时页码从头重数——三者都会让溯源标签失效。

## 5. 入库落点与状态清单

- 落点：`materials/processed/<考试>/`，文件名保留原卷标识（如 `2020-期中.md`），与既有材料同目录便于对照。
- 状态：更新 `extract_status.csv`，该文件的状态列标 **「外部AI转写」**（区别于本机文本层提取与手工录入）；同一份材料重转时更新状态行的日期，不新增重复行。
- 落库后走入口 A 建库流程（分档判定见 `material_tiers.md`）；转写件里的页码锚点即建库时溯源标签的来源。
- 只要该材料被引用过一次，`extract_status.csv` 的状态就不能留空——状态空白的材料在下一次会话里会被当成「来源不明」。

## 6. 与其他文件的衔接

- **SKILL.md**：入口 A 的「材料入库」一步引用本文的转写与质检流程；外部执行、技能落账的边界由 SKILL.md 声明。
- **material_tiers.md**：转写质量影响档位判断（缺锚点 → 溯源降级为 `[AI 补充]`）；「解析 ≠ 细则」同样适用于转写回来的解析段落。
- **measurement_guide.md**：留出集的题若来自转写件，`p.N` 锚点是核对「这道题确实出自该卷」的依据。
- **extract_status.csv**：第 5 节的状态值「外部AI转写」是本文的落账口径，不另设状态名。
