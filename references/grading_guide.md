# 批改指南：推理链优先 + 采分点命中（grading_guide）

> 升级自 test_tutor@a25df33 的 `references/grading_guide.md`（客观题标准答案比对、主观题采分点三约束）。
> 本文是批改方法论真源：SKILL.md 第 4 节引用本文；测量层前后测操作见 `measurement_guide.md`；
> 推理链三态的统计口径见 `error_taxonomy.md` 第 6 节。

## 1. 两层分离：先分清这次批改为谁服务

| | 练习层（日常） | 测量层（留出集前后测） |
|---|---|---|
| 题型 | 主观题为主 | 客观题为主（M-A 可含主观题） |
| 批改主体 | AI 批改，允许漂移 | 客观题：用户对照答案自批；主观题：盲评同批 |
| 有模型参与吗 | 有 | **客观题路径零 LLM**；主观题路径有（见 §7） |
| 目的 | 给反馈 | 记分 |
| 不准的代价 | 建议偏差 | 验证失效 |

**把「零 LLM」的适用范围写清楚**（这是对旧文档表述的修正）：留出集的客观题路径从出题到记分不经任何模型，漂移为零；M-A 档的主观题必须走「盲评同批法」——两次测量放进**同一个对话、同一个模型实例、一次性批完**，靠「共享同一个当下」抵消漂移，而不是靠没有模型。两者都合法，但不能混为一谈：前者是机制上的零参与，后者是统计上的同源偏差抵消。

## 2. 推理链优先：为什么要先判链，再判答案

采分点命中解决的是「给分漂移」，没解决「蒙对不算对」。一道题答对但说不出依据，说明这次对了不代表会——如果它照样进掌握度分子，掌握度就会被运气抬高，后续复习优先级排序也跟着错。所以 v1.5 把批改拆成两步：

1. **先判推理链**（结构是否成立）；
2. **再判答案**（对不对 / 采分点命中）。

顺序不能换：先看答案再看链，判定会被正确答案锚定（"他都答对了，过程应该没问题吧"），这是批改者的确认偏差。

### 2.1 推理链三态（列值只有这三个）

| 值 | 判据 | 谁写 |
|---|---|---|
| `成立` | 写出了支撑答案的关键依据：客观题至少给出「用到的条件/规则 + 为什么排除其它选项」中的一项；主观题覆盖关键步骤清单的**全部**步骤 | 客观题由 AI 判（须引原句）；主观题见 §4；测量层由用户自判 |
| `不成立` | 写了依据但依据错、缺关键步骤、或自陈「我是蒙的 / 猜的」 | 同上 |
| `未写` | 完全没有作答依据（外部录入题、或你跳过了这一步） | 会话内 AI 按实际情况记 |

- **答对 + `不成立` = 疑似蒙对**：不计入掌握度分子，强制进变式题池（`weekly_report.py` 单列）。
- **答对 + `未写`**：不惩罚、不记蒙对，但周报会点名——外部录入题可以长期留空，技能出的题不该空。
- **答错 + 任意链态**：链态只用于诊断（错在结构还是错在执行），不影响「错」的记录。

### 2.2 客观题的链判定怎么做（一句话也要可核验）

客观题没有过程，所以只要求一行依据。判定时同样受三约束（见 §3.2）：**每个判定必须引用作答原句**。

| 作答 | 判定 | 依据列写法 |
|---|---|---|
| 「因为同源染色体在减Ⅰ分离，所以 B」 | 成立 | 引「同源染色体在减Ⅰ分离」 |
| 「选 B，感觉是 B」 | 不成立 | 引「感觉是 B」——没有条件/规则 |
| 「B」 | 不成立（没写=没依据） | 作答里没有任何依据可引 |
| 「我记不清了，蒙的」 | 不成立（自陈蒙） | 引「蒙的」 |

## 3. 客观题判分：标准答案比对（测量层唯一合法路径）

1. 出题后、作答前先标信心（三档见 `error_taxonomy.md` 第 2 节），**再写一行依据**，最后给答案——顺序固定。
2. 作答完成，对照材料自带的标准答案逐题判「对 / 错」；判分路径中没有模型打分环节。
3. 对错进 `answer_log.csv`「对错」列，依据判定进「推理链」列，信心与错因同行。
4. 标准答案缺失或存疑的题**不进判分序列**——拿不准的答案没有测量意义。

测量层里，第 2 步的「对错」与「推理链」都由**你**对照 `held_out.md` 里预先固定的答案与关键步骤清单判定（见 `measurement_guide.md` 第 3 节），会话模型不参与。

## 4. 主观题批改：链判定表 + 采分点命中表

原理不变：把评分拆成二值清单，让模型做判定而不是打分。v1.5 在命中表前加一张**链判定表**。

### 4.1 两步模板（可整体复制）

```
你是阅卷人。先判推理链，再判采分点。全程不给总分、不给等级。

【题目】...

【关键步骤清单】（来自官方评分细则 / 材料解析，共 K 步）
1. ...
2. ...
3. ...

【考生作答】
（逐字粘贴，不改写、不摘要）

第一步：输出推理链判定表
| 关键步骤 | 是否出现 | 依据（引用作答原句关键词） |
|---|---|---|
| 1 | 出现 / 未出现 | ... |

步骤判定结论（只选一个）：
- 成立：全部关键步骤出现且次序、条件正确
- 不成立：缺 ≥1 个关键步骤，或次序/条件错（部分成立一律按不成立计，并注明缺口）

第二步：仅当步骤结论为「成立」或「答案正确但步骤不成立」时，输出采分点命中表
| 采分点 | 命中 | 依据（引用作答原句关键词） |
|---|---|---|
| 1 | 完全/部分/未命中 | ... |
| 2 | ... | ... |

然后输出：
- 遗漏的采分点编号：
- 每个遗漏点的一句话提示（只提示，不要给完整答案）：

约束：
- 只判断要点与步骤是否出现，不给整体分数、不给等级评价
- 每个判定必须引用作答中的原句作为依据；找不到依据就判“未命中/未出现”
- 不要评价语言流畅度、篇幅、字迹
```

### 4.2 三约束与各自对应的偏差

| 约束 | 对应偏差 |
|---|---|
| 不给总分 | 分数趋中、「掐头去尾」（好答卷被压低、弱答卷被拔高） |
| 每个判定必须引用作答原句，找不到依据判「未命中」 | 长度偏差、对表面特征过度敏感 |
| 不评语言流畅度、篇幅、字迹 | 直接屏蔽模型最容易被迷惑的维度 |

证据背景：对 761 篇本科论文的研究显示，前沿模型评分与专家学位等级仅约半数相符，且对篇幅、词汇量等表面特征过度敏感——这是「不要分数、只要命中」的依据。链判定表沿用同一条纪律：**每一步都要有原句，没有就是没出现**。

### 4.3 使用规则

- 关键步骤清单的来源决定它能否进测量层：M-A 档从官方细则机械提取；M-B/M-C 档由 AI 现拟并标 `[AI 补充]`，**只用于练习层**（分档见 `material_tiers.md`）。
- 「未命中」不可凭感觉推翻：先看依据列，没有原句引用就维持「未命中」。
- 当次「对错」由你结合两张表自判拍板后记入 `answer_log.csv`（标注权在你）。
- 遗漏点的「一句话提示」就是反馈的正式形态；给完整答案会削弱下次同类练习的价值。

### 4.4 输出示例（合成值，仅示格式）

第一步 · 推理链判定表

| 关键步骤 | 是否出现 | 依据 |
|---|---|---|
| 1 说明两条链反向平行 | 出现 | 「两条链反向平行，所以碱基互补配对」 |
| 2 指明转录模板链 | 未出现 | 只写了「转录」，未指明哪条链作模板 |
| 3 写出碱基配对规则 | 出现 | 「A 配 T、G 配 C」 |

步骤判定结论：**不成立**（缺关键步骤 2）

第二步 · 采分点命中表

| 采分点 | 命中 | 依据 |
|---|---|---|
| 1 反向平行 | 完全 | 「两条链反向平行」 |
| 2 模板链 | 未命中 | （作答中找不到相关原句） |
| 3 配对规则 | 完全 | 「A 配 T、G 配 C」 |

- 遗漏的采分点编号：2
- 提示：回看转录的模板选择（只提示，不给完整答案）

## 5. 疑似蒙对的落地

| 步骤 | 动作 |
|---|---|
| 判定 | `answer_log.csv` 一行内：`对错=对` 且 `推理链=不成立` |
| 记账 | 不改 `对错`（它记录的是答案对不对），只改链列 |
| 计算 | `mastery_calc.py` 在正确率、惩罚、趋势三处把该行按错计 |
| 出题 | 进变式题池；变式题**必须写出完整推理链**，不能只给答案 |
| 观测 | `weekly_report.py` 单列「疑似蒙对」清单（模块 + 日期） |

## 6. 外部大模型批改（可选）

想用另一家模型/另一台设备批改时，AI 把【关键步骤清单】+【题目】+【考生作答】+ 两步模板 + 三约束组装成一段**可整体复制的提示词**；你粘贴给外部模型，把结果回贴，AI 按同一规则落账。

- 外部模型只给了命中表、没给链判定表 → **只取命中表**，链判定退回会话内重做一遍（链是 v1.5 的记账前提，不能缺）。
- 依据列没有原句引用 → 该点按「未命中 / 未出现」计。
- 输出跑题/拒答/格式崩坏 → 重试一次（提示词开头加「只输出两张表与遗漏点提示」），再失败换模型或回会话内批改。
- 给了总分/等级 → 忽略分数。
- 边界：技能不注册、不登录任何外部服务，不自动调用外部 API；提示词由你手动复制粘贴。

## 7. 测量层的推理链判定

| 题型 | 谁判链 | 依据 | 有没有模型 |
|---|---|---|---|
| 客观题 | 你 | `held_out.md` 内建库时固定的关键步骤清单 | 无 |
| 主观题（M-A） | 盲评同批中的阅卷模型 | 官方细则提取的步骤清单 | 有（同批同源） |

关键约束：**测量层的链判定不读 Obsidian、不读会话里的历史讨论、不复用练习层的笔记**。它只认 `held_out.md` 里那份清单——清单在建库时一次性写定并纳入哈希，之后不再生成（`measurement_guide.md` 第 2 节）。

## 8. 长度陷阱自检

模型对长答案更宽容。怀疑某次批改因篇幅偏松时：删掉作答三分之一再批一次，对比两次判定——变化就是长度偏差信号。处置是**提醒自己这条反馈可能偏松**，不修正任何记录。测量层不走这条自查，走盲评同批法（两批作答同场批改，篇幅差自然抵消）。
